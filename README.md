# Plumè — Demo interattiva

Concept del sito Estetica Plumè con prenotazioni e agenda dimostrative.

## Avvio
Aprire `index.html` oppure servire la cartella con un server statico.

## GitHub Pages
In Settings → Pages scegliere Deploy from a branch, branch `main`, cartella `/ (root)`.

## Limiti
Nessun backend, login reale o invio email. Prenotazioni salvate soltanto nel browser. Usare dati fittizi. Prezzi, durate e operatrici sono dimostrativi.
